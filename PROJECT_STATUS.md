The primitive calculates a score from a server-supplied seed and successful moves; it does not read or write any leaderboard and is not connected to the UI or production.
- This is not a trusted scoring system. A future server must authenticate and bind the UID, issue and retain challenges, atomically prevent reuse, enforce server-controlled score writes, and validate operational/security limits. Replay cannot prove human play or certify fairness. Existing legacy saves and scores are not verifiable by this prototype and remain untouched. See `security/2048-replay-prototype.md`; production gates remain false.
- Node 22 local verification passed: 72 unit tests, typecheck, lint (five existing warnings), formatting, build and JS budget. The prototype is not imported by the React application. The parent branch's privacy and archive checks passed on GitHub; production scoring remains blocked.
